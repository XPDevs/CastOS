CastOS

Turn any browser into a cast screen. No cables, no account, no server. Works across different networks.

this device Use as CastOS screen Shows the pairing code and receives controls from a phone. phone Open the remote Pair by scanning the code on a CastOS screen.
  1. Open Use as CastOS screen on the TV, laptop or monitor you want to control.
  2. Scan the pairing code with your phone camera, or open the remote and paste the code.
  3. Send the answer code back and control the screen from anywhere.

All traffic is peer to peer over WebRTC. Nothing is stored on a server.
